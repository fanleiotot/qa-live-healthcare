## 关键目录说明
1. **核心代码层**
   - `controller/`: 定义 REST API 接口
   - `service/`: 业务逻辑（接口与实现分离）
   - `repository/`: 数据访问层（JPA/MyBatis）
   - `entity/`: 数据库实体类
   - `dto/`: 数据传输对象

2. **配置与工具**
   - `config/`: Spring 配置类（安全、数据库等）
   - `util/`: 通用工具类（如 JWT 处理）
   - `exception/`: 全局异常处理

3. **多环境支持**
   - `application-{env}.yml`: 环境专用配置

4. **测试**
   - 单元测试与集成测试分离
   - `test-data.sql`: 测试数据初始化

5. **辅助目录**
   - `scripts/`: 部署和数据库迁移脚本
   - `docs/`: 系统架构与 API 文档

> 注：`target/` 为 Maven 编译生成目录，无需手动维护。
